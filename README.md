  # TCP 원격 장치 제어 프로젝트

  TCP를 이용한 라즈베리파이 원격 장치 제어 시스템

  ---

  ## 시스템 구성

  우분투 (클라이언트)                    라즈베리파이 4 (서버)
  ┌──────────────────────┐              ┌──────────────────────┐
  │ CLI 클라이언트        │◄──TCP 1833──►│ 데몬 서버             │
  │ 웹 브라우저           │              │ libdev_led.so        │
  │ C HTTP 웹서버 (8080)  │              │ libdev_light.so      │
  └──────────────────────┘              │ libdev_seg.so        │
                                        │ libdev_buzzer.so     │
                                        └──────────────────────┘

  ---

  ## 개발 환경

  | 항목 | 내용 |
  |------|------|
  | 서버 | 라즈베리파이 4 (ARM aarch64) |
  | 클라이언트 | Ubuntu Linux (x86-64) |
  | 서버 포트 | TCP 1833 |
  | 웹 포트 | HTTP 8080 |

  ---

  ## 의존성 설치 (우분투)

  ```bash
  sudo apt install gcc make git gcc-aarch64-linux-gnu

  ---
  빌드

  git clone https://github.com/ys9991113-lgtm/TCP_PROJECT.git
  cd TCP_PROJECT
  make

  make 한 번으로 전부 빌드:

  ┌───────────────────┬────────────────────────────────┐
  │       파일        │              설명              │
  ├───────────────────┼────────────────────────────────┤
  │ cross/server      │ 라파용 ARM 서버 (크로스컴파일) │
  ├───────────────────┼────────────────────────────────┤
  │ cross/libdev_*.so │ 라파용 ARM 공유 라이브러리     │
  ├───────────────────┼────────────────────────────────┤
  │ client            │ 우분투용 CLI 클라이언트        │
  ├───────────────────┼────────────────────────────────┤
  │ web/webserver     │ 우분투용 C HTTP 웹서버 (epoll) │
  └───────────────────┴────────────────────────────────┘

  ---
  라파 배포

  # 라파로 파일 전송
  scp cross/server <계정>@<라파IP>:~/project/
  scp cross/libdev_*.so <계정>@<라파IP>:~/project/lib/

  # 라파에서 서버 시작 (데몬으로 백그라운드 실행)
  cd ~/project
  sudo ./server

  # 서버 로그 확인
  cat /tmp/tcpserver.log

  ---
  실행

  # 클라이언트 + 웹서버 + 브라우저 자동 실행
  make run

  # 라파 IP가 다를 때
  make run PI_HOST=<라파IP>

  ---
  서버 종료

  make stop

  ---
  CLI 클라이언트 메뉴

  1) LED ON(최대)    2) LED ON(중간)
  3) LED ON(최저)    4) LED OFF
  5) 조도 읽기
  6) 7세그 표시(0~9)
  7) 부저 ON         8) 부저 OFF
  9) 카운트다운(0~9)  → 0 도달 시 부저 자동 울림
  10) AUTO ON        11) AUTO OFF
  0) 종료

  ┌────────┬───────────────────────┐
  │   키   │         동작          │
  ├────────┼───────────────────────┤
  │ Ctrl+C │ 정상 종료             │
  ├────────┼───────────────────────┤
  │ Ctrl+Z │ 무시 (강제 종료 불가) │
  ├────────┼───────────────────────┤
  │ Ctrl+\ │ 무시 (강제 종료 불가) │
  └────────┴───────────────────────┘

  ---
  웹 인터페이스

  브라우저: http://localhost:8080/

  ┌─────────────┬──────────────────────────┐
  │    기능     │           설명           │
  ├─────────────┼──────────────────────────┤
  │ 조도 그래프 │ 1초마다 실시간 갱신      │
  ├─────────────┼──────────────────────────┤
  │ LED 제어    │ 최대/중간/최저/OFF       │
  ├─────────────┼──────────────────────────┤
  │ 부저 제어   │ ON/OFF                   │
  ├─────────────┼──────────────────────────┤
  │ 카운트다운  │ 0~9, 0 도달 시 부저 울림 │
  ├─────────────┼──────────────────────────┤
  │ 7세그먼트   │ 0~9 직접 표시            │
  ├─────────────┼──────────────────────────┤
  │ AUTO 모드   │ 조도센서 → LED 자동 제어 │
  └─────────────┴──────────────────────────┘

  ---
  구현 기능

  ┌───────────┬────────────────────────────────┐
  │   장치    │              기능              │
  ├───────────┼────────────────────────────────┤
  │ LED       │ ON/OFF, 밝기 3단계 (softPWM)   │
  ├───────────┼────────────────────────────────┤
  │ 부저      │ 학교종 멜로디 ON/OFF           │
  ├───────────┼────────────────────────────────┤
  │ 조도센서  │ PCF8591 I2C, 실시간 값 읽기    │
  ├───────────┼────────────────────────────────┤
  │ 7세그먼트 │ 0~9 표시, 카운트다운+부저 연동 │
  └───────────┴────────────────────────────────┘

  서버 로그/PID

  /tmp/tcpserver.log   # 서버 로그

  ┌────────────┬───────────────────────────────┐
