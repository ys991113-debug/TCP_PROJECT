 # TCP 원격 장치 제어 프로젝트

  TCP를 이용한 라즈베리파이 원격 장치 제어 시스템

  ---

  ## 시스템 구성

      라즈베리파이 4 (서버)                   우분투 (개발/클라이언트)
  ┌─────────────────────────────┐         ┌────────────────────────────┐
  │  TCP 서버 (데몬, 1833)       │◄──TCP───│  CLI 클라이언트 (client)   │
  │   ├ libdev_led.so           │  1833   └────────────────────────────┘
  │   ├ libdev_light.so         │
  │   ├ libdev_seg.so           │         ┌────────────────────────────┐
  │   └ libdev_buzzer.so        │◄──HTTP──│  웹 브라우저               │
  │                             │  8080   │  (tailscale IP로 어디서든) │
  │  웹서버 (webserver, 8080)   │         └────────────────────────────┘
  │  (서버 시작 시 자동 실행)    │
  └─────────────────────────────┘
  - 서버·웹서버 모두 라파에서 실행 (크로스컴파일)
  - sudo ./server 하나로 TCP서버 + 웹서버 동시 시작

  ---

  ## 개발 환경

  | 항목 | 내용 |
  |------|------|
  | 서버 | 라즈베리파이 4 (ARM aarch64) |
  | 개발/클라이언트 | Ubuntu Linux (x86-64) |
  | 언어 | C (C11) |
  | TCP 포트 | 1833 (장치 제어) |
  | HTTP 포트 | 8080 (웹 모니터링) |
  | GPIO | wiringPi |
  | A/D 변환 | PCF8591 (I2C, 0x48) |
  | JSON | jsmn |
  | 크로스 컴파일 | aarch64-linux-gnu-gcc |
  | 네트워크 | Tailscale VPN |

  ---

  ## 의존성 설치 (우분투)

  ```bash
  sudo apt install gcc make git gcc-aarch64-linux-gnu -y

  ---
  빌드

  git clone https://github.com/ys9991113-lgtm/TCP_PROJECT.git
  cd TCP_PROJECT
  make

  make 한 번으로 전체 빌드:

  ┌───────────────────┬──────────┬───────────────────────┐
  │      산출물       │ 아키텍처 │         용도          │
  ├───────────────────┼──────────┼───────────────────────┤
  │ cross/server      │ ARM      │ 라파 TCP 서버 (데몬)  │
  ├───────────────────┼──────────┼───────────────────────┤
  │ cross/libdev_*.so │ ARM      │ 라파 장치 라이브러리  │
  ├───────────────────┼──────────┼───────────────────────┤
  │ cross/webserver   │ ARM      │ 라파 웹서버 (epoll)   │
  ├───────────────────┼──────────┼───────────────────────┤
  │ client            │ x86      │ 우분투 CLI 클라이언트 │
  └───────────────────┴──────────┴───────────────────────┘

  ---
  라파 배포 (자동)

  make deploy

  → 크로스컴파일 + 라파 전송 + 서버 자동 시작 한 번에 완료.
  (라파 sudo 비번 한 번 입력 필요)

  라파 배포 (수동)

  scp cross/server     <계정>@<라파IP>:~/project/
  scp cross/libdev_*.so <계정>@<라파IP>:~/project/lib/
  scp cross/webserver  <계정>@<라파IP>:~/project/
  scp web/index.html   <계정>@<라파IP>:~/project/web/

  ---
  실행

  1) 라파에서 — 서버 + 웹서버 한 번에

  cd ~/project
  sudo ./server

  → TCP 서버(1833) + 웹서버(8080) 동시 자동 시작

  2) 우분투에서 — CLI 클라이언트

  make run
  # 또는 IP 직접 지정
  make run PI_HOST=<라파IP>

  3) 브라우저 — 웹 대시보드 (tailscale 연결된 어디서든)

  http://<라파 tailscale IP>:8080/
  예) http://100.83.88.7:8080/

  ---
  서버 종료

  make stop

  ---
  CLI 클라이언트 메뉴

  1) LED ON(최대)    2) LED ON(중간)
  3) LED ON(최저)    4) LED OFF
  5) 조도 읽기
  6) 7세그 표시(0~9)
  7) 부저 ON         8) 부저 OFF
  9) 카운트다운(0~9)  → 0 도달 시 부저 자동 울림
  10) AUTO ON        11) AUTO OFF
  0) 종료

  ┌────────────────┬───────────────────────┐
  │       키       │         동작          │
  ├────────────────┼───────────────────────┤
  │ Ctrl+C         │ 정상 종료             │
  ├────────────────┼───────────────────────┤
  │ Ctrl+Z, Ctrl+\ │ 무시 (강제 종료 불가) │
  └────────────────┴───────────────────────┘

  ---
  웹 인터페이스 기능

  ┌─────────────┬──────────────────────────┐
  │    기능     │           설명           │
  ├─────────────┼──────────────────────────┤
  │ 조도 그래프 │ 1초마다 실시간 갱신      │
  ├─────────────┼──────────────────────────┤
  │ LED 제어    │ 최대/중간/최저/OFF       │
  ├─────────────┼──────────────────────────┤
  │ 부저 제어   │ ON/OFF                   │
  ├─────────────┼──────────────────────────┤
  │ 카운트다운  │ 0~9, 0 도달 시 부저      │
  ├─────────────┼──────────────────────────┤
  │ 7세그먼트   │ 0~9 직접 표시            │
  ├─────────────┼──────────────────────────┤
  │ AUTO 모드   │ 조도센서 → LED 자동 제어 │
  └─────────────┴──────────────────────────┘

  ---
  구현 기능

  ┌───────────┬────────────────────────────────┐
  │   장치    │              기능              │
  ├───────────┼────────────────────────────────┤
  │ LED       │ ON/OFF, 밝기 3단계 (softPWM)   │
  ├───────────┼────────────────────────────────┤
  │ 부저      │ 학교종 멜로디 ON/OFF           │
  ├───────────┼────────────────────────────────┤
  │ 조도센서  │ PCF8591 I2C, 실시간 값 읽기    │
  ├───────────┼────────────────────────────────┤
  │ 7세그먼트 │ 0~9 표시, 카운트다운+부저 연동 │
  └───────────┴────────────────────────────────┘

  ---
  프로젝트 구조

  TCP_PROJECT/
  ├── src/
  │   ├── server/      # 서버 (main.c, proto.c, loader.c)
  │   ├── devices/     # 장치 드라이버 (.so 소스)
  │   └── client/      # CLI 클라이언트
  ├── web/             # 웹서버(C, epoll) + index.html
  ├── cross/           # 크로스컴파일용 wiringPi (헤더/라이브러리)
  ├── include/         # 공통 헤더 (device.h, jsmn.h)
  ├── 실행과정.txt
  └── Makefile

  ---
  Makefile 타깃

  ┌─────────────┬───────────────────────────────┐
  │    명령     │             동작              │
  ├─────────────┼───────────────────────────────┤
  │ make        │ 전체 빌드 (크로스컴파일 포함) │
  ├─────────────┼───────────────────────────────┤
  │ make deploy │ 라파 전송 + 서버 자동 시작    │
  ├─────────────┼───────────────────────────────┤
  │ make run    │ CLI 클라이언트 실행           │
  ├─────────────┼───────────────────────────────┤
  │ make stop   │ 라파 서버 종료                │
  ├─────────────┼───────────────────────────────┤
  │ make clean  │ 빌드 산출물 삭제              │
  └─────────────┴───────────────────────────────┘

  ---
  주요 기술

  - TCP 멀티스레드 서버 / JSON 프로토콜 (jsmn)
  - 동적 라이브러리(.so) 플러그인 구조 (dlopen)
  - 데몬 프로세스 + 시그널 처리 (SIGTERM 안전 종료)
  - 크로스 컴파일 (우분투 → 라파 ARM)
  - 동기화 (dispatch_mutex / auto_mutex / countdown semaphore)
  - epoll 기반 HTTP 웹서버
