 # TCP_PROJECT

  라즈베리파이 원격 장치 제어 시스템 (LED · 조도센서 · 7세그먼트 · 부저)

  ## 구조

  | 머신 | 역할 |
  |------|------|
  | 우분투 | 빌드(크로스 컴파일) · 배포 · CLI 클라이언트 |
  | 라즈베리파이 4 | TCP 서버 + 웹서버 (하드웨어 연결) |

  > 라파에서 `sudo ./server` 하나로 TCP 서버 + 웹서버가 동시에 실행됩니다.

  ## 빌드 (우분투)

  ```bash
  sudo apt install gcc make git gcc-aarch64-linux-gnu -y   # 최초 1회
  git clone https://github.com/ys9991113-lgtm/TCP_PROJECT.git
  cd TCP_PROJECT
  make

  배포 + 실행

  # 우분투에서 라파로 전송
  make deploy PI_HOST=<라파IP> PI_USER=<계정> PI_DIR=/home/<계정>/project
   - 수동으로도가능 -
  # 라파에서 서버 실행
  cd ~/project
  sudo ./server

  - 웹 접속: http://<라파IP>:8080/
  - CLI 클라이언트: make run PI_HOST=<라파IP>
  - 서버 종료: make stop 또는 라파에서 sudo kill $(cat /tmp/tcpserver.pid)

  Makefile 명령

  ┌─────────────┬────────────────┐
  │    명령     │      동작      │
  ├─────────────┼────────────────┤
  │ make        │ 전체 빌드      │
  ├─────────────┼────────────────┤
  │ make deploy │ 라파 전송      │
  ├─────────────┼────────────────┤
  │ make run    │ CLI 클라이언트 │
  ├─────────────┼────────────────┤
  │ make stop   │ 서버 종료      │
  ├─────────────┼────────────────┤
  │ make clean  │ 산출물 삭제    │
  └─────────────┴────────────────┘

  기능

  ┌───────────┬────────────────────────────────────┐
  │   장치    │                기능                │
  ├───────────┼────────────────────────────────────┤
  │ LED       │ ON/OFF, 밝기 3단계 (softPWM)       │
  ├───────────┼────────────────────────────────────┤
  │ 부저      │ 학교종 멜로디 ON/OFF               │
  ├───────────┼────────────────────────────────────┤
  │ 조도센서  │ PCF8591 I2C, 실시간 값 (웹 그래프) │
  ├───────────┼────────────────────────────────────┤
  │ 7세그먼트 │ 0~9 표시 / 카운트다운 → 0에서 부저 │
  └───────────┴────────────────────────────────────┘

  부가: 웹 대시보드 · AUTO 모드(조도→LED) · 다중 클라이언트(CLI+웹 동시)

  기술

  - TCP 멀티스레드 서버 / JSON 프로토콜(jsmn)
  - 동적 라이브러리(.so) 플러그인 구조(dlopen)
  - 데몬 + 시그널 처리(SIGTERM 안전 종료)
  - 크로스 컴파일(x86 → ARM aarch64)
  - 동기화(mutex / semaphore)
  - epoll 기반 HTTP 웹서버
